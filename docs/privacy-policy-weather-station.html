WXStation Connect – Privacy Policy

Last update: 2026-03-10

Important: WXStation Connect does not collect personal data. It requires a Weather Underground API key provided by the user to function — without it, no data can be retrieved. The key is stored only on the user's device and is never accessible by the developer. All connections go directly from the device to the Weather Underground API; there is no proprietary server or backend.

Política de Privacidad (es-ES)

2. Datos personales

  • No requiere registro ni cuenta.
  • No solicita nombre, email, teléfono ni ubicación personal del usuario.
  • No vende ni comparte datos personales.

WXStation Connect requiere una API key de Weather Underground proporcionada por el propio usuario para funcionar. Los datos recibidos de la API no se almacenan en ningún servidor, ni se venden ni se redistribuyen en ninguna forma. WXStation Connect es una aplicación independiente y no está afiliada, respaldada ni patrocinada por Weather Underground ni por The Weather Company, LLC.

La disponibilidad de los datos meteorológicos depende del servicio de API de Weather Underground, operado por un tercero ajeno al control del desarrollador. El desarrollador no se hace responsable de cualquier interrupción, modificación o discontinuación de dicho servicio.
