Política de Privacidad (es-ES)

1. Introducción

WXStation Connect permite consultar datos de estaciones meteorológicas publicadas en Weather Underground. Esta app no recopila datos personales del usuario.

2. Datos personales

  • No solicita nombre, e-mail, teléfono ni ubicación personal del usuario.

La API key se usa localmente en el dispositivo para el funcionamiento de la app y sus widgets, y nunca es accesible por el desarrollador. En cada solicitud de datos meteorológicos, la API key se transmite a los servidores de Weather Underground cifrada mediante HTTPS/TLS.

4. Almacenamiento local

La app guarda de forma local configuraciones como estaciones, unidades e idioma. No existe ningún servidor propio donde se almacene información del usuario.

Las previsiones meteorológicas opcionales por horas (~60 h) y hasta 10 días se obtienen a través de la API Locationforecast 2.0 de MET Norway (Instituto Meteorológico de Noruega, met.no, bajo licencia CC BY 4.0). La comunicación está cifrada mediante HTTPS/TLS. Únicamente se transmiten las coordenadas geográficas públicas de la estación (redondeadas a 4 decimales) y su altitud satelital, junto con una cabecera estándar User-Agent identificativa de la aplicación exigida por los términos de uso de MET Norway; no se envía ningún dato personal, ubicación GPS del dispositivo ni clave API de Weather Underground. Las respuestas se almacenan en caché localmente en el dispositivo. WXStation Connect es una aplicación independiente y no está afiliada, respaldada ni patrocinada por MET Norway.

Para las estaciones situadas en Estados Unidos y territorios estadounidenses, la previsión opcional por horas (72 h) y hasta 7 días, así como las alertas meteorológicas oficiales activas, se obtienen mediante la API pública de NOAA / National Weather Service (weather.gov, api.weather.gov). La comunicación está cifrada mediante HTTPS/TLS. Únicamente se transmiten las coordenadas geográficas públicas de la estación (redondeadas a 4 decimales) junto con una cabecera estándar User-Agent identificativa de la aplicación exigida por las condiciones de la API de NOAA / NWS; no se envía ningún dato personal, ubicación GPS del dispositivo ni claves API de Weather Underground. Solo se transmiten las coordenadas geográficas públicas de la estación o el nombre de la localidad buscada; no se envía ningún dato personal ni la ubicación del dispositivo.

Al utilizar el mapa interactivo para buscar estaciones cercanas, las teselas cartográficas se cargan directamente desde los servidores de OpenStreetMap (openstreetmap.org). La aplicación no solicita permisos de ubicación GPS ni envía la ubicación física del dispositivo.

Estas coordenadas son procesadas por Ventusky conforme a su propia política de privacidad.

Optional hourly (~60 h) and up to 10-day weather forecasts are obtained through the Locationforecast 2.0 API operated by MET Norway (Norwegian Meteorological Institute, met.no, under CC BY 4.0). Communication is encrypted via HTTPS/TLS. Only the weather station's public geographic coordinates (rounded to 4 decimal places) and its satellite elevation are transmitted, together with a standard app identification User-Agent header required by MET Norway's Terms of Service; no personal data, device GPS location, or Weather Underground API keys are sent. Responses are cached locally on the device. WXStation Connect is an independent app and is not affiliated with, endorsed by, or sponsored by MET Norway.

For stations located in the United States and U.S. territories, optional 72-hour hourly forecasts, up to 7-day forecasts, and official active weather alerts are obtained via the public NOAA / National Weather Service API (weather.gov, api.weather.gov). Communication is encrypted via HTTPS/TLS. Only the weather station's public geographic coordinates (rounded to 4 decimal places) are transmitted, together with a standard app-identifying User-Agent header required by NOAA / NWS API terms; no personal data, device GPS location, or Weather Underground API keys are sent. Coverage status and responses are cached locally on the device. When opening an alert's external link on weather.gov, public station coordinates and alert zone parameters are passed in the browser URL. WXStation Connect is an independent app and is not affiliated with, endorsed by, or sponsored by NOAA or the National Weather Service.

Sky condition detection, air quality data, satellite elevation for forecast calibration, and city search in the station discovery map are provided by the Open-Meteo API (open-meteo.com), an open-source weather service. Only the weather station's public geographic coordinates or the searched locality name are transmitted; no personal data or device location is sent.

When using the interactive map to discover nearby stations, map tiles are loaded directly from OpenStreetMap servers (openstreetmap.org). The app does not request GPS location permissions or send the device's physical location.

Upcoming solar and lunar eclipse data is obtained through the OPALE API operated by IMCCE – Paris Observatory (opale.imcce.fr). Communication is encrypted via HTTPS/TLS. For solar eclipses, only the weather station's public geographic coordinates are transmitted; lunar eclipse queries do not send coordinates. Responses are cached locally on the device. No personal data or API keys are sent. WXStation Connect is not affiliated with IMCCE or the Paris Observatory.

A link to the Ventusky weather radar service (ventusky.com) is included in the app. When opened, the weather station's public geographic coordinates are transmitted as URL parameters in the device browser. These coordinates are processed by Ventusky under their own privacy policy.

Firebase Analytics (Google) is used to collect anonymous usage statistics and register in-app purchase events for advertising attribution purposes. This data is processed by Google under their own Privacy Policy (https://policies.google.com/privacy).

6. Data security

All communication between the app and the Weather Underground service is encrypted using HTTPS/TLS. The API key and station settings are stored securely on the device.
