Weather Station – Privacy Policy

Last update: 2026-02-19

Important: The app does not collect personal data. It only displays weather data from Weather Underground stations using the API key configured locally by the user.

Política de Privacidad (es-ES)

1. Introducción

Estación Meteorológica permite consultar datos de estaciones publicadas en Weather Underground. Esta app no recopila datos personales del usuario.

2. Datos personales

  • No requiere registro ni cuenta.
  • No solicita nombre, email, teléfono ni ubicación personal del usuario.
  • No vende ni comparte datos personales.

3. API key y estaciones Weather Underground

La app utiliza la API key introducida por el usuario únicamente para consultar datos meteorológicos de sus estaciones en Weather Underground. Dicha API key se usa localmente en el dispositivo para el funcionamiento de la app y sus widgets.

4. Almacenamiento local

La app guarda de forma local configuraciones como estaciones, unidades e idioma. No existe backend propio para almacenar información del usuario.

5. Terceros

Los datos meteorológicos proceden de Weather Underground, sujeto a sus propios términos y políticas.

Privacy Policy (en-US)

1. Introduction

Weather Station lets users view data from stations published on Weather Underground. This app does not collect personal data.

2. Personal data

  • No sign-up or account is required.
  • No name, email, phone, or personal location is requested.
  • No personal data is sold or shared.

3. API key and Weather Underground stations

The app uses the API key provided by the user only to request weather data from the user's Weather Underground stations. The API key is used locally on the device for app and widget functionality.

4. Local storage

The app stores settings locally (stations, units, language). There is no proprietary backend collecting user information.

5. Third parties

Weather data is provided by Weather Underground and is subject to its own terms and privacy policies.

Datenschutzerklärung (de-DE)

1. Einleitung

Weather Station zeigt Daten von auf Weather Underground veröffentlichten Stationen an. Die App erhebt keine personenbezogenen Daten.

2. Personenbezogene Daten

  • Keine Registrierung oder Benutzerkonto erforderlich.
  • Kein Name, keine E-Mail, keine Telefonnummer und kein persönlicher Standort werden angefragt.
  • Es werden keine personenbezogenen Daten verkauft oder weitergegeben.

3. API-Schlüssel und Weather-Underground-Stationen

Die App verwendet den vom Nutzer angegebenen API-Schlüssel ausschließlich, um Wetterdaten der eigenen Weather-Underground-Stationen abzurufen. Der API-Schlüssel wird lokal auf dem Gerät verwendet.

4. Lokale Speicherung

Einstellungen wie Stationen, Einheiten und Sprache werden lokal gespeichert. Es gibt kein eigenes Backend zur Erfassung von Nutzerdaten.

5. Dritte

Wetterdaten stammen von Weather Underground und unterliegen deren eigenen Richtlinien.
