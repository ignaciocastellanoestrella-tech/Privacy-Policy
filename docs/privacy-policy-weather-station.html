WXStation Connect – Privacy Policy

Weather Station App

Last update: 2026-04-13
Important: WXStation Connect does not collect personal data. It requires a Weather Underground API key provided by the user to function — without it, no data can be retrieved. The key is stored only on the user's device and is never accessible by the developer. All connections go directly from the device to the Weather Underground API using HTTPS/TLS encryption; there is no proprietary server or backend. The app uses Firebase Analytics (Google) to collect anonymous usage statistics and register in-app purchase events for advertising attribution purposes. This data is processed by Google under their own privacy policy.

Política de Privacidad (es-ES)

1. Introducción

WXStation Connect permite consultar datos de estaciones meteorológicas publicadas en Weather Underground. Esta app no recopila datos personales del usuario.

2. Datos personales

  • No requiere registro ni cuenta.
  • No solicita nombre, e-mail, teléfono ni ubicación personal del usuario.
  • No vende ni comparte datos personales.

3. API key y estaciones Weather Underground

WXStation Connect requiere una API key de Weather Underground proporcionada por el propio usuario para funcionar. Sin ella, la aplicación no puede obtener datos meteorológicos ni mostrar ninguna información. La API key se usa localmente en el dispositivo para el funcionamiento de la app y sus widgets, y nunca es accesible por el desarrollador. En cada solicitud de datos meteorológicos, la API key se transmite a los servidores de Weather Underground cifrada mediante HTTPS/TLS.

4. Almacenamiento local

La app guarda de forma local configuraciones como estaciones, unidades e idioma. No existe ningún servidor propio donde se almacene información del usuario.

5. Terceros

Los datos meteorológicos son proporcionados por The Weather Company, LLC (Weather Underground) y están sujetos a sus propios términos y políticas. Los datos recibidos de la API no se almacenan en ningún servidor, ni se venden ni se redistribuyen en ninguna forma. WXStation Connect es una aplicación independiente y no está afiliada, respaldada ni patrocinada por Weather Underground ni por The Weather Company, LLC.

La disponibilidad de los datos meteorológicos depende del servicio de API de Weather Underground, operado por un tercero ajeno al control del desarrollador. El desarrollador no se hace responsable de cualquier interrupción, modificación o cese de dicho servicio.

La app utiliza Firebase Analytics (Google) para recopilar estadísticas de uso anónimas y registrar eventos de compra con fines de atribución publicitaria. Estos datos son procesados por Google conforme a su Política de Privacidad (https://policies.google.com/privacy).

La app incluye un enlace al servicio de radar meteorológico Ventusky (ventusky.com). Al pulsar dicho enlace, las coordenadas geográficas de tu estación meteorológica se transmiten como parámetros en la URL al abrirse en el navegador del dispositivo. Estas coordenadas son procesadas por Ventusky conforme a su propia política de privacidad.

6. Seguridad de los datos

Toda la comunicación entre la aplicación y el servicio de Weather Underground se realiza mediante cifrado HTTPS/TLS. La API key y la configuración de estaciones se almacenan de forma segura en el propio dispositivo.

Privacy Policy (en-US)

1. Introduction

WXStation Connect lets users view data from weather stations published on Weather Underground. This app does not collect personal data.

2. Personal data

  • No sign-up or account is required.
  • No name, email, phone, or personal location is requested.
  • No personal data is sold or shared.

3. API key and Weather Underground stations

WXStation Connect requires a Weather Underground API key provided by the user in order to function. Without it, the app cannot retrieve any weather data and will not display any information. The API key is used locally on the device for app and widget functionality and is never accessible by the developer. With each weather data request, the API key is transmitted to Weather Underground's servers, encrypted via HTTPS/TLS.

4. Local storage

The app stores settings locally (stations, units, language). There is no developer-owned server collecting user information.

5. Third parties

Weather data is provided by The Weather Company, LLC (Weather Underground) and is subject to its own terms and privacy policies. Data received from the API is not stored on any server, sold, or redistributed in any form. WXStation Connect is an independent app and is not affiliated with, endorsed by, or sponsored by Weather Underground or The Weather Company, LLC.

The availability of weather data depends on the Weather Underground API service, which is operated by a third party beyond the developer's control. The developer is not responsible for any interruption, modification, or discontinuation of that service.

The app uses Firebase Analytics (Google) to collect anonymous usage statistics and register in-app purchase events for advertising attribution purposes. This data is processed by Google under their own Privacy Policy (https://policies.google.com/privacy).

The app includes a link to the Ventusky weather radar service (ventusky.com). When tapping this link, the geographic coordinates of your weather station are transmitted as URL parameters when opened in the device browser. These coordinates are processed by Ventusky under their own privacy policy.

6. Data security

All communication between the app and the Weather Underground service is encrypted using HTTPS/TLS. The API key and station settings are stored securely on the device.
